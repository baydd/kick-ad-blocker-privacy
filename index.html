Privacy Policy — Kick Ad Blocker

Last updated: August 24, 2026

This privacy policy describes how the Kick Ad Blocker Chrome extension ("the extension", "we") handles information. The extension blocks in-stream (SSAI) video ads on kick.com, lets you recolor the site with your own theme, sends live notifications for favorite channels, and optionally provides a built-in AI Chat Bot.

1. Information We Do NOT Collect

The extension does not collect, store, or transmit any of the following to us:

  • Personal identification information (name, email address, phone number)
  • Account credentials or passwords (including your Kick login)
  • Payment or financial information
  • Health or biometric data
  • Location data or IP addresses
  • Browsing history
  • Keystrokes, mouse movements, or any other input data
  • We do not have analytics, telemetry, tracking pixels, or developer-side logging of any kind

2. Information Stored Locally on Your Device

All settings and data below are stored only in your browser's local storage (Chrome storage.local) and never leave your device unless you explicitly use the AI feature described in section 3:

  • Extension settings: ad-blocking mode, theme color, language, interface accent color.
  • Favorite channels: the channel names you add for live notifications.
  • AI Chat Bot configuration: bot on/off state, personas (names, trigger words, personality prompts), custom commands, cooldowns, and the API key of the AI provider you choose. Your API key is stored locally and is sent only to that provider when you use the bot.
  • Memory notes about chat users: short text notes the AI writes to remember preferences of viewers who talk to it. These notes stay in local storage, can be viewed and deleted at any time in the extension's Settings → Memory panel, and are never uploaded anywhere by us.
  • Learned emote codes: a list of kick.com emote codes seen in chat, used so the bot can reply with native platform emotes.
  • Statistics: a simple counter of blocked ads, kept locally.

3. AI Chat Bot Feature (Optional, Off by Default)

The AI Chat Bot is disabled until you turn it on and paste your own API key. When enabled and someone in chat addresses the bot:

  • What is sent: the chat message that triggered the reply, the persona's personality prompt, global instructions, a short recent conversation history with that viewer (if memory is enabled), the viewer's public chat nickname, and small locally stored memory notes about that viewer.
  • Where it is sent: directly from your browser to the AI provider you selected — Google Gemini (generativelanguage.googleapis.com), OpenAI (api.openai.com), Groq (api.groq.com), or OpenRouter (openrouter.ai) — using your own API key. The request is made by the extension's service worker; the developer never sees your key, your prompts, or the responses.
  • Provider policies apply: what those providers do with the content is governed by their own terms and privacy policies (for example, Google's Gemini API terms include human review of some free-tier traffic). Choose a paid tier or a different provider if this matters to you.
  • The bot reads only the messages needed to answer; it does not silently upload the whole chat room.

4. Network Requests

The extension makes only these requests:

  • A request to the official Kick API (kick.com) to obtain the ad-free playback URL of the channel you are currently watching (page context, no personal data).
  • A periodic request to the same Kick API to check whether your favorite channels are live (only if you added favorites and notifications are on).
  • Requests to your chosen AI provider's endpoint, only when the AI Chat Bot is used (see section 3).

5. Data Sharing

We do not sell, trade, rent, or share any user data with third parties. The only external recipients of any content are the AI providers you explicitly configure, and only for messages you send through the bot. Everything else remains on your device.

6. Third-Party Content

The extension popup contains a donation button that links to buymeacoffee.com. Clicking this button is an optional action taken by the user and is subject to Buy Me a Coffee's own privacy policy. The button image is loaded directly from the Buy Me a Coffee CDN.

7. Children's Privacy

The extension does not knowingly collect any information from children under the age of 13.

8. Changes to This Policy

We may update this privacy policy from time to time. Any changes will be posted on this page with an updated revision date. This version covers the features introduced in v1.3.0, including the AI Chat Bot with multiple provider support.

9. Contact

If you have any questions about this privacy policy, please contact the developer through the Chrome Web Store listing page of the Kick Ad Blocker extension.
